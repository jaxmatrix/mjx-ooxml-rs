# Generated-type coverage

_Generated by `cargo run -p xtask -- codegen`; do not edit by hand._

Every schema of the ECMA-376 Transitional set has a row in **both** tables, so a schema can never be uncovered *and* unlisted. The status of each row is derived — from the generator's module table and from `CHILD_ORDER_SCHEMAS` — never written down, so a later change flips its own row.
