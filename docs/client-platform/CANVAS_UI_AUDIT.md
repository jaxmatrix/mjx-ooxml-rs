# The in-canvas UI audit — one line per element

Generated by `cargo run -p mjx-canvas-harness -- checklist`. **Nothing in this file is ticked, and no agent may tick it.** The boxes are for the person doing the pass.

## How to run the pass

```sh
cargo run -p mjx-canvas-harness -- serve
```

Open the address it prints. The scene list is on the left, the state panel on the right. For each element below:

1. Look at it at **1×, 2× and 3×**, in **light and dark**. The density toggle is the one that finds a hairline that has vanished or doubled.
2. Step the **interaction** toggle through default, hover, active, focused and disabled. An element whose toggle does nothing is either finished or wrong, and the harness's own gate says which — see the `responds to` column.
3. Turn on the **hit-test overlay** and judge the grab region. Then set **input** to touch and judge it again.
4. For the eleven touch elements, **open the harness on a phone** (`serve --host 0.0.0.0`, then the machine's address on the same network) and use a thumb. A touch target judged with a mouse has not been judged.
5. Tweak whatever is wrong in the **token editor**. It writes back to `docs/client-platform/data/tokens.json`; run `cargo run -p xtask -- tokens` afterwards to carry the change into the three generated artefacts.
6. When an element is right, tick its box here, and record the approval against its plate:

```sh
MJX_ORACLE_APPROVED_BY='Your Name' \
  cargo run -p mjx-canvas-harness -- approve <number> "why"
```

**Human review: 0 of 61.** A plate approved by the generator is a real approval record — the digest binding is live, so a silent regeneration is caught — and it is *not* a person having looked at the image.

## What this checklist does not cover

* **Behaviour.** Nothing here is wired to a document, to selection or to editing — that is loop 2. The elements are *exercised*, not *connected*.
* **The chrome.** Toolbars, panels and dialogues are web components and are audited in Storybook; this is the surface that cannot be one.
* **Parity with PowerPoint.** These are this platform's own design, not a reproduction of somebody else's, so there is nothing to be at parity with. Every plate records `parity: false` and it is computed rather than written.
