THE WEAKEST PART, STATED PLAINLY
--------------------------------------------------------------------------------

The evidence scanner reads Rust source with a line scanner rather than a parser.
It strips comments before counting, refuses a provenance ledger whose rows do not
pair up rather than reading it wrongly, and NAMES in the generated document any file
it could not read — `crates/mjx-layout-xlsx/tests/the_format_language_is_evaluated.rs`
is such a file today, because it writes its tiers through a `use` alias. Every way the
scan can be wrong is the conservative one: fewer assertions counted means a LOWER
state, never a higher one, and provenance not read means a row reports no declared
evidence rather than borrowed evidence.

That is a real mitigation and it is not a proof. A file that reorganised its ledger
into a shape the scanner reads *differently* rather than *not at all* would be
miscounted silently. The structural answer would be for the suites to emit a
machine-readable artefact of their own — but that would put this generator downstream
of a `cargo test` run, and the ticket is explicit that it must run no renderer and
judge nothing itself.

The second-weakest part is the row table. The rows are a hand-drawn partition of
`OFFICE_FEATURE_INVENTORY.md`, written in the same file that names each row's evidence,
so the denominator is not independent of the numerator. A coarser partition would raise
the implemented share without a line of code changing. The generated document says
exactly that, in its own `## Where the denominators come from` section, and takes no
percentage against the row count anywhere.

The third is the evidence pointers themselves. A row can under-report by pointing at
too few suites, and nothing catches that — the liveness check only catches a pointer to
a suite that is gone, never a suite that should have been pointed at. Three rows were
corrected on exactly this ground while reviewing the first generated output
(`pptx-master-and-layout`, `table-selection`, `pptx-slide-authoring`), which is evidence
that the failure mode is real and that only a reader finds it.
