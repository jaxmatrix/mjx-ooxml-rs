        inside that string. It had looked right for two children only because
        the token of that name always came first; a seed carrying the metadata
        now precedes it. Fixed by requiring the object to be the value
        immediately after the colon.
      · a test asserting `previous == "{color.green-deep}"` — a committed value
        written into a suite. Rewritten to assert the property (it is an alias)
        rather than which alias.
